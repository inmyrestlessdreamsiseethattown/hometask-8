
# Вариант 16 — Сумма ряда

## Условие задачи

Вычислите с использованием цикла `for` значение для заданного целого `n`:

    1 - 1/2 + 1/4 - 1/8 + ... + (-1)^n * 1/2^n

### Условие

Каждый член ряда имеет вид:

    a_k = (-1)^k / 2^k,  где k = 0, 1, 2, ..., n

Сумма вычисляется по формуле:

    S = Σ (от k=0 до n) (-1)^k / 2^k

То есть знак чередуется (+, -, +, -), а знаменатель удваивается:
2^0 = 1, 2^1 = 2, 2^2 = 4, 2^3 = 8, ...

### Алгоритм

1. Ввести целое число `n` (n ≥ 0).
2. Проверить корректность ввода (n ≥ 0).
3. Инициализировать сумму `S = 0.0` и текущий член `term = 1.0`.
4. В цикле `for (k = 0; k <= n; k++)`:
   - добавить `term` к `S`;
   - вычислить следующий член: `term = -term / 2.0`.
5. Вывести значение суммы `S` с точностью 6 знаков.
6. Вывести количество просуммированных членов (n + 1).

### Код программы

```c
#include <stdio.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "RUS");

    int n;
    double S = 0.0;
    double term = 1.0;   /* текущий член ряда, начнём с 1 (k = 0) */
    int k;

    printf("Введите целое n (n >= 0): ");
    if (scanf("%d", &n) != 1) {
        fprintf(stderr, "Ошибка: ожидалось целое число.\n");
        return 1;
    }

    if (n < 0) {
        fprintf(stderr, "Ошибка: n должно быть неотрицательным (n >= 0).\n");
        return 1;
    }

    /* Суммируем (n + 1) членов: от k = 0 до k = n */
    for (k = 0; k <= n; k++) {
        S += term;            /* добавляем текущий член */
        term = -term / 2.0;   /* готовим следующий: смена знака и /2 */
    }

    printf("S = %.6f\n", S);
    printf("Количество членов ряда: %d\n", n + 1);

    return 0;
}
```

### Проверка программы

#### Пример 1

Входные данные:

    0

Ряд содержит один член: S = 1.

Результат:

    S = 1.000000
    Количество членов ряда: 1

#### Пример 2

Входные данные:

    1

Ряд: S = 1 - 1/2 = 0.5.

Результат:

    S = 0.500000
    Количество членов ряда: 2

#### Пример 3

Входные данные:

    3

Ряд: S = 1 - 1/2 + 1/4 - 1/8 = 0.625.

Результат:

    S = 0.625000
    Количество членов ряда: 4

#### Пример 4

Входные данные:

    10

Ряд: S = 1 - 1/2 + 1/4 - ... + (-1)^10 * 1/2^10 ≈ 0.666667.

Результат:

    S = 0.666667
    Количество членов ряда: 11

#### Пример 5 (ошибочный ввод)

Входные данные:

    -5

Результат:

    Ошибка: n должно быть неотрицательным (n >= 0).
